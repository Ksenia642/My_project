# My_project — Мои задачи по C#

Учебный сайт с 14 задачами по C#: решения на C#, алгоритмы в виде блок-схем и тестовые примеры.

## Запуск локально
Откройте `index.html` в браузере. Для корректной работы всех функций можно запустить локальный сервер, например расширение Live Server в Visual Studio Code.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий с именем `My_project`.
2. Загрузите в корень репозитория файлы `index.html`, `style.css`, `tasks.js`, `app.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
6. После завершения публикации GitHub покажет адрес сайта в разделе Pages.

## Состав
- `index.html` — структура страницы.
- `style.css` — адаптивный дизайн.
- `tasks.js` — условия, решения, шаги блок-схем и тесты для 14 задач.
- `app.js` — фильтрация, поиск, раскрытие карточек и копирование кода.

Все решения приведены как отдельные консольные программы. В задачах с несколькими входными значениями их нужно вводить через пробел, если это указано в приглашении.
